WDD 131 Final Project Planning Document

Site Name

Proposed Site Name: DevStack Guide

Domain Availability (Optional): devstackguide.dev or devstackguide.io

Name Justification

The name "DevStack Guide" was chosen because it cleanly communicates the exact purpose of the site: a modern, practical reference for a developer's environment, extensions, and workflow stack. The .dev domain TLD immediately signifies a developer-focused technical resource.

Branding & Logo Representation

Logo Concept: The concept blends the MDW initials into an isometric workspace featuring a multi-monitor developer setup, enclosed in a dynamic circular frame to represent a modern, high-tech engineering environment.

Site Purpose

Scope & Goals: A curated web resource dedicated to optimizing modern code editors like VS Code, keyboard shortcuts, essential developer extensions, and terminal setups. To help Beginners and intermediate developers looking to boost their productivity and streamline their dev environment

  • Home: Overview of modern developer productivity principles and a showcase of trending developer tools.
  • Editor Setup: Recommended VS Code extensions, custom visual themes, and productivity-boosting keybindings tailored for web development.
  • Workflow Tips: Terminal enhancements (Zsh, Starship, Powerlevel10k), essential Git workflows, and custom snippet management.
  • Interactive Tool: A dynamic "Shortcut Cheat Sheet Generator" allowing developers to select their OS (macOS/Windows) and editor to generate and filter essential keyboard shortcuts.

Target Audience Scenarios

These target user questions drive the site structure, interactive features, and content organization:

  • Scenario 1 (Beginner Web Developer): "I just installed VS Code for my web development bootcamp. What essential extensions and keyboard shortcuts will speed up my HTML/CSS/JS coding without overwhelming me?"
  • Scenario 2 (Intermediate Developer / Career Switcher): "How can I customize my terminal and Git workflow so I can run commands faster and avoid looking up basic Git commands every day?"
  • Scenario 3 (Productivity Seekers): "Can I quickly generate a customized printable or filterable list of VS Code shortcuts specific to my Mac operating system?"

Application Rules

  • Dark Slate (#1E1E2E): Page background.
  • Charcoal (#282A36): Content cards, header containers, and navigation bars.
  • Bright Cyan (#80EBD9): Main title headers, primary links, and visual accents.
  • Soft Purple (#BD93F9): Section headings (<h2>) and button borders.
  • Neon Green (#50FA7B): Interactive buttons, active tab states, and snippet code highlights.
